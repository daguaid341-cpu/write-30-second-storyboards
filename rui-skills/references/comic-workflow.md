# 漫剧制作流程

作为 Rui-Skills 视频流程，开始前必须完成[统一服务器验证](local-verification.md)。未获本次许可时停止，不回退到本机授权；独立人物设定图不受此要求影响。

在主技能选择「漫剧」后读取本文件。默认每组30秒、中文交付、无BGM和字幕。默认画风为2D动漫，用户指定国风、日漫、美漫、3D动画或其他画风时按指定执行；先写明采用的画风，无需为已有明确设定重复确认。

## 从故事到制作资料

一句剧情直接写分镜；整剧按需使用改编大纲、剧本和分镜模块，并读取已有角色、美术资料，不执行它们的设计工作流。角色动机、对白、知情范围、场景轴线、道具归属和时间覆盖仍按[连续性流程](script-continuity.md)检查。将项目模式记录为 `comic`，沿用本项目已选画风。

沿用已有角色的轮廓、比例、线条和衣饰，以及既定场景与道具；这些是连续性检查依据，不是新设计清单。视频提示词优先引用资产，仅描述剧情和动作需要的已有细节，不自行补造衣服配色、款式或环境结构。用户明确要求真人转漫剧时说明风格转换；若还要求重新设计设定图，另作独立资产任务。

## 表演和镜头

- 根据剧情选择清楚可读的关键姿态、表情变化、眼神目标和反应时点；夸张程度由人物与已选画风决定。可以使用动画停顿与有限动作，但不新增对白、情节或无因动作。
- 写清「起始姿态 → 关键动作 → 停顿/反应 → 结束姿态」。描述需要活动的层：角色、嘴型、发丝/衣摆、道具、前景、背景。静止人物配移动背景或景深层时说明动作边界，避免全画面无意义漂移。
- 镜头用景别、视角、透视、构图、虚拟机位、推拉摇移和切点表达；2D模式可用分层视差或关键帧运动。仅在用户需要时写虚拟焦距，不默认套用实拍机型、光圈或真人毛孔词。
- 口型、动作、对白和反应占真实时间；30秒装不下就拆成多组，不擅删对白。速度线、漫画拟声字、字幕或文字特效仅在用户明确要求时使用。

## 默认交付

**统一提示词：** 画幅、选定画风、线条与上色方式、固定角色造型、色板、背景空间、光影风格和声音约束。

**30秒漫剧分镜：** 逐镜连续覆盖0–30秒，列出景别/视角/虚拟运镜、构图、角色姿态与表情、关键帧起止、各层运动、对白和切点。需要投产文件时按模块schema整理JSON，`cut.lens`可写「标准透视」等虚拟镜头描述；可选 `cut.animation` 补充层运动，`cut.visualTreatment` 补充线条与上色，不把物理摄影参数当漫剧必填语义。

**约束：** 角色造型、头身比、线条、色板与上色稳定；人数、衣饰、轴线和道具不漂移；无未授权文字、字幕与BGM。

## 视频验收

检查既有造型与画风连续性、关键姿态、层运动、口型与时间。设定图与三视图设计不属于本流程。仅完成脚本检查时视觉状态仍为未验证。
